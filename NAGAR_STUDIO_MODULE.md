# Nagar Studio Mobile

This Android application is the mobile companion to Nagar Studio.

The phone owns the mobile UI and local/offline queueing roadmap. Speech generation remains in the Nagar Studio service so desktop and mobile share the same voices, pronunciation rules and production behavior.

Default emulator endpoint: `http://10.0.2.2:3000`

For a physical Android device, use the host PC's LAN address and ensure Windows Firewall permits the Nagar Studio port on the private network.
